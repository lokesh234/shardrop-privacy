# Prismfall privacy policy

A single static page (`index.html`) with no build step and no external requests. It adapts to light and dark mode and works on phone screens.

## Before publishing

1. Replace `YOUR_CONTACT_EMAIL` in `index.html` with the address you want players to use.
2. If anything about the app's data handling changes (new ad network, analytics, accounts), update the page and the effective date.

## Host it free on GitHub Pages

1. Create a public repo, e.g. `prismfall-privacy`, and push this folder to it.
2. In the repo, open **Settings → Pages**, set **Source** to *Deploy from a branch*, and choose `main` and `/ (root)`.
3. The policy will be live at `https://<your-username>.github.io/prismfall-privacy/`.

Use that URL in App Store Connect (**App Privacy → Privacy Policy URL**) and in the AppLovin sign-up.
